# DBMS Lab Work

A collection of my DBMS lab work, because apparently we need to prove that we know SQL by writing SQL.

This repo contains the usual stuff:

* DDL & DML
* Table creation and modification
* Inserts, updates, deletes
* Queries and joins
* Constraints
* Other lab exercises that will inevitably appear on the syllabus

### For Juniors

If you're here because you have the same lab:

**yoink whatever you need.**

Copy the queries, change the names, steal the schema, whatever helps. I'm not going to pretend this repo contains some revolutionary database engineering.

Just make sure you change things where required and, preferably, understand roughly what the query does before the viva. 😭

The work is mostly written for **PostgreSQL / Neon**, so if your lab uses Oracle or MySQL, a few things might need changing.

That's it.

Good luck surviving DBMS.
